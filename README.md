# chaos-go

Reverse proxy на Go для одного HTTP- или HTTPS-сервера. Адрес целевого сервера задаётся при запуске. По умолчанию прокси принимает HTTP-запросы на `127.0.0.1:8080`.

## Запуск

Требуется Go 1.25 или новее. Если сервис уже слушает на `127.0.0.1:9000`, запустите прокси из корня репозитория:

```sh
go run . -upstream http://127.0.0.1:9000/api
```

В другом терминале отправьте запрос:

```sh
curl -i 'http://127.0.0.1:8080/items?limit=5'
```

Прокси передаст запрос на `http://127.0.0.1:9000/api/items?limit=5` и вернёт ответ сервиса. Флаг `-listen` задаёт другой адрес прослушивания.

Заголовок `Host` указывает на целевой сервер. В `X-Forwarded-For`, `X-Forwarded-Host` и `X-Forwarded-Proto` прокси передаёт сведения о принятом соединении и запросе. Если соединиться с целевым сервером не удастся, клиент получит `502 Bad Gateway`.

## Проверка

```sh
go test -race ./...
```
